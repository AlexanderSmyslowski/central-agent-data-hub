# v0.2 Definition

Agent Data Hub v0.2 should be the point where the public preview is no longer
only interesting to inspect, but reliable enough to try on a small local project
without maintainer context.

The claim stays narrow:

> reviewed context for humans and agents

v0.2 does not need to be a hosted service, a package-manager product, or a
general automation engine. It needs to make the local reviewed-context loop
boringly reproducible.

## v0.2 Must Prove

1. A new developer can clone the repository, start the public demo, and run the
   smoke path without maintainer-local state.
2. A new local project can be registered, connected to an agent, and used with
   `agent_start` / `agent_finish` without guessing private paths.
3. `agent-hub prepare` produces a task-specific context pack with context
   trail, review labels, known gaps, and deterministic selection behavior.
4. Draft memory candidates stay outside reviewed memory until a human accepts
   or rejects them through CLI or local Hub View.
5. Operational health is visible through doctor, status, check, backup health,
   public demo smoke, fresh-clone CI, and baseline-to-head upgrade drill.
6. Read-only integration surfaces expose reviewed context without adding write
   authority: MCP over stdio, OKF export, Markdown/Obsidian projection, and Hub
   View read surfaces.

## v0.2 Release Gates

Before tagging v0.2, these gates should be true on current `main`:

- `git diff --check`
- `bash -n scripts/*.sh`
- `python -m compileall agent_hub`
- `pytest -q`
- GitHub CI success for Python 3.11 and 3.12
- GitHub CI success for the fresh-clone public demo job
- GitHub CI success for the baseline-to-head upgrade drill
- local `agent-hub status` and `agent-hub check`
- public docs link to the trust model, installation boundary, daily use path,
  and this definition

## Explicitly Not v0.2

These are not required for v0.2 and should not be implied by public docs:

- hosted SaaS
- production auth, roles, or tenancy
- non-checkout package installation as the main path
- automatic memory capture from chats
- background sync workers
- write-capable MCP tools
- embeddings or vector search
- OKF import or two-way sync
- Telegram or other chat adapters inside this repository

## What Good Looks Like

A reasonable outside developer should be able to say:

- I understand the trust claim.
- I can run the demo locally.
- I can see what is reviewed, draft, stale, or missing.
- I can hand a context pack to an agent.
- I can recover from ordinary local setup issues.
- I can tell which paths are public demo paths and which are maintainer
  operator paths.

That is the v0.2 bar.
