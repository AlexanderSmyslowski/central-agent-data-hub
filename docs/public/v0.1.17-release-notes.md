# Agent Data Hub v0.1.17

Agent Data Hub v0.1.17 is a small product-coherence documentation release after
the v0.1.16 operational hint cleanup.

## What Changed

- `docs/public/daily-use.md` now describes the canonical daily local workflow
  after the public demo.
- The README now bridges from the neutral demo into real local project use:
  register a project, start with reviewed context, work inside that boundary,
  and finish with an auditable handoff.
- The public getting-started guide now points readers to the daily-use path
  once the demo makes sense.
- Regression tests keep this daily-use path linked and scoped to reviewed
  local context rather than broad product claims.

## Boundaries

- no schema change
- no migration
- no new dependency
- no new Hub-memory write path
- no hosted service
- no new automation surface

## Release Position

v0.1.17 does not add a feature. It makes the existing system easier to
understand as a daily local workflow: public demo first, registered project,
visible agent handoff, explicit review, finish, receipt, and backup.
