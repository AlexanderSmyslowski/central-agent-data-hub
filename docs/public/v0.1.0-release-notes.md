# Agent Data Hub v0.1.0

Agent Data Hub v0.1.0 is the first small public open-source release.

It should be read as a local-first reviewed-context system for humans and
agents, not as a finished hosted product.

## What This Release Includes

- PostgreSQL-backed reviewed memory
- compact agent start context through `compile`, `start`, and `context` flows
- quality checks, receipts, and backup verification
- Markdown/Obsidian projection
- Hub View as a local read-only review surface
- a neutral public demo path

## Recommended First Run

Start from a fresh checkout with Python 3.11+, Docker, and Docker Compose.
Make sure Docker is running before starting the database.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
cp .env.example .env

scripts/db_start_public_demo.sh
scripts/smoke_public_demo.sh
scripts/hub_view.sh
```

For the fuller walkthrough, use
[`docs/public/getting-started.md`](getting-started.md).

## What Changed Recently

- public technical preview docs were simplified and made less maintainer-local
- the public demo path is separated more clearly from the maintainer's local ops path
- the neutral sample flow can be smoke-tested end to end
- local PostgreSQL now uses password authentication instead of `trust`
- `.env.example`, Docker Compose, scripts, and tests now share the same local password default
- local demo container, volume, and port names can be overridden for isolated clean-clone tests
- minimal GitHub Actions CI runs shell syntax checks, Python compilation, and tests on Python 3.11 and 3.12
- Hub View scripts now live under the main `scripts/` convention
- recent Python review findings were addressed: less variable shadowing, typed workflow connections, parameterized sync-event metadata, and less duplicated write-result code
- project-start guardrails block mismatched project/workdir starts

## Known Boundaries

- this is a local-first system, not a hosted service
- some maintainer-local ops scripts and seeds still exist alongside the public demo path
- the public demo path does not wipe an existing local database automatically
- the project favors clarity and reviewability over broad automation

## Release Position

v0.1.0 is suitable for:

- developers exploring reviewed memory for agent workflows
- local experiments with project-bound agent context
- small technical evaluations

It is not yet positioned as a broad end-user product.
