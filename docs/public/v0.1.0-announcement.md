# Agent Data Hub v0.1.0

reviewed context for humans and agents

Agent Data Hub is a small local-first system for reviewed project memory,
compact agent start context, and human-readable review surfaces.

It is built for people who want something stricter than ordinary chat memory:

- reviewed memory in PostgreSQL
- compact project context for agent runs
- Markdown/Obsidian projection for humans
- quality checks, receipts, and backup verification
- a neutral public demo path

Recommended first run:

```bash
scripts/db_start_public_demo.sh
scripts/smoke_public_demo.sh
scripts/hub_view.sh
```
