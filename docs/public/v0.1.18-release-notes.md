# Agent Data Hub v0.1.18

Agent Data Hub v0.1.18 is a small operational reliability release for the
public demo and daily local workflow.

## What Changed

- `scripts/smoke_public_demo.sh` now verifies the demo `prepare` path in both
  JSON and Markdown form.
- The smoke checks that the Context Trail, Known Gaps, stale threshold, and
  deterministic task-selection mode are visible in the demo context pack.
- The smoke exports OKF twice from the same demo input and diffs the bundles,
  so wall-clock timestamps or unstable output fail locally.
- The daily-use guide now states what the public demo smoke proves before a
  user relies on the path for real project work.
- Regression tests keep the smoke tied to prepare, gaps, OKF determinism, and
  public daily-use documentation.

## Boundaries

- no schema change
- no migration
- no new dependency
- no new Hub-memory write path
- no hosted service
- no broad automation surface

## Release Position

v0.1.18 does not add a feature. It makes the existing public demo and daily
local path more falsifiable: the smoke now proves that the system can prepare
reviewed context with gaps and produce a stable OKF preview bundle.
