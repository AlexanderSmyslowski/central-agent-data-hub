# Agent Data Hub v0.1.21

Agent Data Hub v0.1.21 is a v1.0 adoption-readiness cleanup release.

## What Changed

- The public demo and configured local-ops startup paths are separated more
  clearly. Private operator seeds must live outside Git and be passed
  explicitly; the repository ships only neutral demo seed data.
- The public demo hygiene guard now checks for non-demo projects generically
  instead of carrying maintainer-specific project names.
- Repo-wide examples, tests, operator templates, and import examples now use
  neutral demo project names and placeholder paths.
- `AGENTS.md` and operator templates use repo-relative or placeholder paths
  instead of machine-local maintainer paths.
- The v1.0 release path is now framed as an adoption-readiness gate: automated
  evidence is required, and the real human first-run proof remains a separate
  pre-tagging requirement.

## Boundaries

- no schema change
- no migration
- no new dependency
- no packaging change
- no hosted service
- no new Hub-memory write path
- no new review channel

## Release Position

v0.1.21 does not add capability. It makes the repository easier to evaluate as
an outside developer: the first public path is neutral, examples are anonymous,
and v1.0 remains defined as local reviewed-context infrastructure rather than a
finished product or automation platform.

Do not tag or broadly promote v1.0 until the first-run protocol has been run
with a real technical tester, or the deferral is recorded explicitly in release
notes.
