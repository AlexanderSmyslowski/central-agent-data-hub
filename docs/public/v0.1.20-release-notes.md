# Agent Data Hub v0.1.20

Agent Data Hub v0.1.20 is a v0.2-readiness cleanup release.

## What Changed

- Public wording now uses "reviewed context" instead of overclaiming external
  verification.
- `docs/public/trust-model.md` documents what reviewed memory means and what it
  does not guarantee.
- `docs/public/installation.md` makes the v0.2 preview installation boundary
  explicit: the git checkout is the installation unit.
- Checkout-bound CLI helpers now fail with an explicit checkout message when
  their backing scripts are unavailable.
- CI now includes an `upgrade-drill` job that migrates an untracked baseline
  schema to HEAD and then runs the public demo smoke.
- Maintainer/operator notes moved under `docs/operator/` with a clear boundary
  note.

## Boundaries

- no schema change
- no migration
- no new dependency
- no hosted service
- no new Hub-memory write path
- no new product feature

## Release Position

v0.1.20 does not add capability. It makes the public preview easier to evaluate
honestly: the trust claim is narrower, installation expectations are explicit,
upgrade behavior is tested, and maintainer-local notes are separated from the
public path.
