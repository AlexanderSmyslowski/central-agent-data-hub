# Agent Data Hub v0.1.19

Agent Data Hub v0.1.19 is a small reliability proof release for the public demo
path.

## What Changed

- CI now includes a fresh-clone public demo job on `ubuntu-latest`.
- The job follows the documented manual public demo path: create a virtual
  environment, install the checkout, copy `.env.example`, start the isolated
  demo database, run the public demo doctor, and run the public demo smoke.
- The existing unit-test matrix remains on Python 3.11 and 3.12.
- Regression tests keep the CI drill tied to the public demo path instead of a
  maintainer-local database.

## What This Proves

- A clean Ubuntu runner can execute the documented public demo path.
- A clean GitHub Actions runner can start the neutral public demo database.
- The demo doctor can diagnose the same isolated database.
- The public smoke can verify prepare output, Context Trail, Known Gaps, OKF
  determinism, Markdown export, and Hub View rendering on a fresh runner.

## Boundaries

- no schema change
- no migration
- no new dependency
- no new Hub-memory write path
- no hosted service
- no new product feature

## Release Position

v0.1.19 does not make Agent Data Hub more automatic. It makes the public demo
claim easier to trust: CI now checks the documented path on a clean Ubuntu
runner, not only on the maintainer machine.
