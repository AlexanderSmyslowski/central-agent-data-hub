# Agent Data Hub v0.1.14

Agent Data Hub v0.1.14 is a small public-preview hygiene release after the
v0.1.13 first-run compression.

## What Changed

- `seed/README.md` now explains that the repository ships only the neutral public demo seed.
- The README Startup Paths section links to that seed boundary so outside
  developers can see that private operator seeds belong outside Git and must be
  passed explicitly.
- A regression test keeps the public demo seed path separate from private local
  ops seed files.

## Boundaries

- no schema change
- no migration
- no new dependency
- no new Hub-memory write path
- no hosted service
- no automatic promotion
- no change to the public first-run command

## Release Position

v0.1.14 keeps the same technical-preview scope as v0.1.13. It does not add a
feature; it makes the public repository easier to read by keeping shipped seed
data neutral and documenting where private local operator seed files belong.
